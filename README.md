# 國中自然科學學習講義（第 1 冊 · 生物）互動學習單

依《國中自然科學學習講義 第1冊》製作的單檔 HTML 互動教材，共 30 份學習單與 1 個總覽頁。
每份都是**完全獨立的單檔 HTML**，沒有任何外部相依（無 CDN、無外部圖檔、無字型檔；
角色插圖與顯微鏡構造圖都內嵌在檔案裡），直接用瀏覽器打開就能用，也可以整個資料夾丟上 GitHub Pages 或 Netlify。

---

## 快速開始

**本機使用**：直接用瀏覽器打開 `index.html`。

**GitHub Pages 部署**：

1. 在 GitHub 新建一個 repository（例如 `bio1-worksheets`）。
2. 把這個資料夾裡的所有檔案上傳到 repository 根目錄。
3. 進入 **Settings → Pages**，Source 選 **Deploy from a branch**，
   Branch 選 `main` / `(root)`，按 Save。
4. 等一兩分鐘，網址會是 `https://<你的帳號>.github.io/<repo 名稱>/`。

`.nojekyll` 這個空檔案要一起上傳，否則 GitHub Pages 可能會忽略某些檔案。

**Netlify 部署**：把資料夾直接拖到 Netlify 的 Deploy 區塊即可，不需要建置指令。

## 技術約定

新增或修改檔案時請沿用以下約定，避免破壞既有功能。

### 作答暫存

每份檔案有自己的 `localStorage` key，格式為 `nature1-<代號>-v1`，例如：

```js
var KEY = "nature1-c5-3-v1";
```

所有讀寫都包在 `try/catch` 中，在無痕模式或停用 localStorage 的環境下仍可正常作答，
只是重新整理後不會保留。

### 共用錯題本

所有檔案共用同一個 key：

```js
var WB_KEY = "nature1-wrongbook-v1";
```

每筆紀錄的欄位：

| 欄位 | 說明 |
|---|---|
| `sheet` | 學習單標題 |
| `file` | 檔名，供總覽頁產生連結 |
| `tag` | 題目來源（焦點即時練／實力養成評量／歷屆經典題…） |
| `q` | 題目文字 |
| `why` | 解題重點 |
| `answer` | 正確答案 |
| `wrong` | 累計答錯次數 |
| `fixed` | 是否已訂正（錯過之後又答對） |
| `last` | 最後答錯日期 |

### 語音導覽

使用瀏覽器內建的 Web Speech API，語音挑選順序為 `zh-TW` → `zh-HK` → 其他中文。
內含 8 秒 watchdog，用來處理 Chrome 朗讀長句時中斷的問題。測驗卷版型不含此功能。


### 實驗紀錄互動元件（NKit）

實驗活動紀錄簿的內容以共用的 `window.NKit` 產生，四種元件都只吃資料、不用另外寫 DOM：

| 元件 | 用途 | 主要欄位 |
|---|---|---|
| `NKit.fill()` | 句子填空 | `rows[].t` 中每個 `{}` 換成一個下拉選單；`ans` 為答案陣列，加 `any:true` 表示同列答案不分順序 |
| `NKit.order()` | 步驟排序 | `steps` 以**正確順序**給，畫面上會依 `host` 名稱固定打散 |
| `NKit.table()` | 比較表／紀錄表 | `head` 欄位標題，`rows[].cells` 每格給 `opts`／`ans`，給 `text` 則是不作答的固定內容 |
| `NKit.check()` | 複選勾選 | `items[].ok` 標出應勾選的項目 |

每個元件共用同一個 `cfg.key`（格式 `nature1-<代號>-lab-v1`），與該份學習單原本的作答暫存分開存放。
按鈕和回饋訊息會自動插在該區塊正下方，不需要自己寫 `<button>`。

元件的 CSS 集中在樣式表最後的「實驗紀錄共用元件」區塊（`.sub`／`.kfill`／`.kord`／`.kchk`／`.kgrid`
與 `table.cmp`）。注意多數檔案原本有 `select{width:100%;}`，所以 `.kfill`／`.kord` 內的選單
另外指定了 `width:auto`，新增區塊時不要拿掉。

### 顯微鏡互動構造圖

`bio1-c1-1.html` 內含手繪的 SVG 複式顯微鏡與解剖顯微鏡（`#scopeCard`），各 13 個構造。
操作方式是**先點圖上的構造，再從下方名稱中選**；答對會填成綠色並顯示該構造的功能。
構造以 `data-k` 標定，名稱與功能寫在腳本的 `PARTS` 物件中，進度存在 `nature1-scope-v1`。
圖形是純 SVG 路徑，沒有點陣圖，縮放不會失真。

### 生物陪讀家教　李憲緹（粒線體）

所有 32 個 HTML 檔在 `</body>` 前都注入同一段區塊，以
`<!-- ===== 生物陪讀家教　李憲緹（粒線體）　START ===== -->` 與對應的 `END` 註解包住，
內含 CSS、HTML 與一個獨立 IIFE，所有元素 id／class 一律以 `lxt` 開頭，不會和原有程式衝突。

角色圖片以 **base64 WebP 內嵌**，維持單檔、無外部相依的原則；
每份學習單因此約增加 230 KB（8 張鼓勵圖 ＋ 1 張頭像），總覽頁另含一張主視覺。

| 時機 | 行為 |
|---|---|
| 進入頁面 | 跳出自我介紹視窗；勾選「下次不用再介紹」後改為一句簡短打氣 |
| 點右下角頭像 | 立刻給一句鼓勵小語（可按「再給我一句」換一則） |
| 每 3～6 分鐘 | 不定時冒出鼓勵卡（與上一次至少間隔 75 秒） |
| 累積 12～20 次作答操作 | 冒出鼓勵卡；未達標時頭像顯示黃點提示 |
| 離開分頁超過 3 分鐘後回來 | 顯示「歡迎回來」 |

語料庫在腳本內的 `POOL` 陣列，每則為 `{k:"圖片代號", t:"文字"}`，省略 `k` 就是純文字小語。
偏好設定存在獨立的 `nature1-tutor-v1`（與作答暫存分開）。
總覽頁與 `index.html` 另有一張家教介紹卡（`.tutor` 區塊，接在 `</header>` 之後），
兩顆按鈕分別呼叫腳本對外暴露的 `window.lxtCheer()` 與 `window.lxtIntro()`。

### 新增一份學習單的步驟

1. 複製 `bio1-c1-3.html`（學習單版型）或 `bio1-c1-map.html`（學習地圖版型）當模板。
2. 修改 `<title>`、`KEY`、`SHEET`（`id` / `title` / `file` 三個欄位都要改）。
3. 換掉重點整理條目、互動練習區與 `QS` 題庫。
4. 到 `bio1-hub.html` 的 `UNITS` 陣列，把對應單元的 `file:""` 填入新檔名。
5. **同步更新 `index.html`**（它是 hub 的副本）。
6. 若要用到實驗紀錄元件，把樣式表裡的「實驗紀錄共用元件」區塊和 `NKit` 腳本一起複製過去。
7. 從既有檔案整段複製 `</body>` 前的「生物陪讀家教」區塊。
8. 用 `node --check` 驗證每個 script 區塊沒有語法錯誤。

### 接尺反應時間計算器

`bio1-c4-1.html` 內含一個小工具（`#rtIn`／`#rtOut`／`#rtTab`）：填入 5 次直尺滑落距離，

對照表資料寫在腳本開頭的 `TAB` 陣列（24 組，2～48 公分），輸入值存在 `nature1-c4-1-rt-v1`。
