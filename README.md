# 國中自然科學學習講義（第 1 冊 · 生物）互動學習單

依《國中自然科學學習講義 第1冊》製作的單檔 HTML 互動教材，共 30 份學習單與 1 個總覽頁。
每份都是**完全獨立的單檔 HTML**，沒有任何外部相依（無 CDN、無圖片、無字型檔），
直接用瀏覽器打開就能用，也可以整個資料夾丟上 GitHub Pages 或 Netlify。

---

## 快速開始

**本機使用**：直接用瀏覽器打開 `index.html`。

**GitHub Pages 部署**：

1. 在 GitHub 新建一個 repository（例如 `bio1-worksheets`）。
2. 把這個資料夾裡的所有檔案上傳到 repository 根目錄。
3. 進入 **Settings → Pages**，Source 選 **Deploy from a branch**，
   Branch 選 `main` / `(root)`，按 Save。
4. 等一兩分鐘，網址會是 `https://<你的帳號>.github.io/<repo 名稱>/`。

`.nojekyll` 這個空檔案要一起上傳，否則 GitHub Pages 可能會忽略某些檔案。

**Netlify 部署**：把資料夾直接拖到 Netlify 的 Deploy 區塊即可，不需要建置指令。

## 三種版型

| 版型 | 適用 | 結構 |
|---|---|---|
| **學習單** | 各節正課 | 學習目標 → 重點整理（可展開、附語音導覽）→ 數個互動練習區 → 練習題 → 答對題數 |
| **學習地圖** | 每章章末 | 重點整理 → 依講義版面排的填答格（①②③…）→ 分區對答案 → 答對格數 |
| **測驗卷** | 複習評量 | 作答說明 → 單題／填充題／題組，每題標配分 → 整卷計分（滿分 100） |

## 技術約定

新增或修改檔案時請沿用以下約定，避免破壞既有功能。

### 作答暫存

每份檔案有自己的 `localStorage` key，格式為 `nature1-<代號>-v1`，例如：

```js
var KEY = "nature1-c5-3-v1";
```

所有讀寫都包在 `try/catch` 中，在無痕模式或停用 localStorage 的環境下仍可正常作答，
只是重新整理後不會保留。

### 共用錯題本

所有檔案共用同一個 key：

```js
var WB_KEY = "nature1-wrongbook-v1";
```

每筆紀錄的欄位：

| 欄位 | 說明 |
|---|---|
| `sheet` | 學習單標題 |
| `file` | 檔名，供總覽頁產生連結 |
| `tag` | 題目來源（焦點即時練／實力養成評量／歷屆經典題…） |
| `q` | 題目文字 |
| `why` | 解題重點 |
| `answer` | 正確答案 |
| `wrong` | 累計答錯次數 |
| `fixed` | 是否已訂正（錯過之後又答對） |
| `last` | 最後答錯日期 |

### 語音導覽

使用瀏覽器內建的 Web Speech API，語音挑選順序為 `zh-TW` → `zh-HK` → 其他中文。
內含 8 秒 watchdog，用來處理 Chrome 朗讀長句時中斷的問題。測驗卷版型不含此功能。

### 新增一份學習單的步驟

1. 複製 `bio1-c1-3.html`（學習單版型）或 `bio1-c1-map.html`（學習地圖版型）當模板。
2. 修改 `<title>`、`KEY`、`SHEET`（`id` / `title` / `file` 三個欄位都要改）。
3. 換掉重點整理條目、互動練習區與 `QS` 題庫。
4. 到 `bio1-hub.html` 的 `UNITS` 陣列，把對應單元的 `file:""` 填入新檔名。
5. **同步更新 `index.html`**（它是 hub 的副本）。
6. 用 `node --check` 驗證 script 區塊沒有語法錯誤。

### 關於改寫過的題目

原卷中依賴插圖（示意圖上的甲乙丙丁代號、曲線圖、實驗裝置圖）的題目，
在轉成純文字介面時，作法是**把圖上的關鍵資訊寫進題幹**，
例如「已知甲為感覺神經元、乙為運動神經元、丙為脊髓」，
或「曲線隨溫度上升而升高，到某一溫度後又急速下降」。
推理過程與正確答案完全保留，只是不需要再對照圖片。

完全無法還原、或原始照片辨讀不清的題目則直接略過，不做臆測。
