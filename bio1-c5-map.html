全章重點整理
  • Start：各器官系統協調合作，維持體內的穩定，稱為恆定性。這一章談的四件事就是體溫、氣體、水分和血糖的恆定。
  • 外溫動物從外界環境中吸收熱量來維持體溫，內溫動物則利用本身代謝作用所產生的熱量。
  • 體溫升高時，腦內的體溫控制中心讓產熱減少（活動力下降）、散熱增加（皮膚微血管血液量增加、汗腺排汗）。
  • 體溫降低時，則是產熱增加（肌肉收縮顫抖、食慾增加）、散熱減少（皮膚微血管血液量減少），最後回到體溫適中。
  • 排泄作用是排除細胞代謝作用產生的代謝廢物：肺經呼氣排出水和二氧化碳，皮膚經流汗排出水、尿素和礦物質，泌尿系統經尿液排出水、尿素和礦物質。
  • 含氮廢物來自蛋白質：蛋白質分解成胺基酸，代謝後產生含氮廢物，也就是氨，再視動物種類轉變成尿素或尿酸。
  • 三種含氮廢物：氨毒性大，見於水中單細胞生物和大多數魚類，以擴散作用排出；尿素見於大部分哺乳類，混在尿液中排出；尿酸毒性小，見於昆蟲和鳥類，混在糞便中排出。
  • 人體的泌尿系統由腎臟、輸尿管、膀胱和尿道組成。
  • 人體的呼吸系統：鼻腔、咽喉、氣管、支氣管、肺。吸氣獲得氧氣，呼氣排除二氧化碳，氣體交換就發生在肺泡。
  • 呼吸運動是吸氣與呼氣的動作：吸氣時肋骨上舉、橫膈下降、胸腔變大、肺變大；呼氣時肋骨下降、橫膈上升、胸腔變小、肺變小。
  • 呼吸作用：細胞利用氧氣，將養分分解，釋放二氧化碳、水與能量。反應式是葡萄糖加氧氣，生成二氧化碳、水和能量。生物所需的能量主要來自呼吸作用。
  • 實驗5-2：檢測水用氯化亞鈷試紙，由藍變紅；檢測二氧化碳用澄清石灰水，由澄清變混濁。
  • 血糖過高時分泌胰島素：一方面讓葡萄糖進入細胞內供利用以消耗血糖，一方面讓肝細胞與肌肉細胞把葡萄糖合成肝糖儲存起來，血糖便降回正常。
  • 血糖過低時分泌升糖素：肝細胞將肝糖轉成葡萄糖釋放至血液，血糖便升回正常。

一、5-1 恆定性與體溫的恆定

Start：各器官系統協調合作，維持體內的穩定，稱為恆定性。

動物從外界環境中吸收熱量來維持體溫
動物利用本身代謝作用所產生的熱量來維持體溫

體溫升高　→　腦內體溫控制中心　→　如何降低？

產熱　減少活動力下降
散熱　皮膚微血管血液量增加、汗腺排汗

體溫降低　→　腦內體溫控制中心　→　如何升高？

產熱　肌肉收縮、顫抖、食慾增加
散熱　減少皮膚微血管血液量減少

兩條路最後都回到：體溫適中。

二、5-4 排泄作用與水分的恆定

排泄作用：排除細胞代謝作用產生的代謝廢物。

呼氣　→　排出水、二氧化碳
皮膚流汗　→　排出水、尿素、礦物質
泌尿系統排出尿液　→　排出水、尿素、礦物質

三、5-2 呼吸與氣體的恆定

人體的呼吸系統：鼻腔、咽喉、氣管、支氣管、肺。吸氣獲得 O₂，呼氣排除 CO₂。

氣體交換的場所　（與微血管間交換氧氣和二氧化碳）

呼吸運動：吸氣與呼氣的動作

　肺橫膈胸腔
吸氣變大上舉下降變大
呼氣變小下降上升變小

作用：細胞利用氧氣，將養分分解，釋放二氧化碳、水與能量。

葡萄糖＋ 氧氣→ 二氧化碳＋ 水＋ 能量

實驗5-2　如何檢驗生物呼吸作用後所呼出的氣體成分？

檢測物檢測劑顏色變化
氯化亞鈷試紙藍 → 紅
二氧化碳澄清石灰水澄清 → 混濁

四、5-3 血糖的恆定

血糖的調控：太高就收起來，太低就放出來。

血糖過高分泌胰島素消耗血糖：葡萄糖進入細胞內，供細胞利用
儲存血糖：肝細胞與肌肉細胞吸收血液中的葡萄糖，合成
血糖過低分泌升糖素增加血糖：肝細胞將肝糖轉成葡萄糖，釋放至血液

兩條路最後都回到：血糖正常。
